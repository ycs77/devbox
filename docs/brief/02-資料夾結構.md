# 資料夾結構

Devbox 的資料夾結構如下：

```text
~/.devbox/
├── config.yaml                    # Global 設定
├── projects.yaml                  # 已註冊專案清單
│
├── projects/
│   └── <專案識別碼>/               # 每個已註冊專案一份
│       ├── config.yaml            # Local 設定
│       └── compose.yaml           # 自動產生的啟動設定
│
├── build/                         # devbox build 時產生，共用一份
│   ├── Dockerfile
│   ├── .dockerignore
│   ├── entrypoint.sh
│   ├── supervisord.conf
│   ├── .bash_aliases
│   ├── .gitconfig
│   ├── AGENTS.md                  # 有設定任何 Agent 時
│   ├── .claude/                   # 有設定 Claude Code 時
│   │   └── settings.json
│   └── .omp/                      # 有設定 OMP 時
│       └── agent/
│           └── config.yml
│
├── agents/
│   └── claude/                    # 有設定 Claude Code 時
│       └── .claude.json           # Claude Code 設定檔
│
└── locks/                         # 指令執行期間的暫時目錄
    ├── global/                    # 全域操作鎖
    └── project-<SHA256>/          # 專案操作鎖
```

## config.yaml

Devbox 的全域設定檔，在第一次執行 `devbox init` 時會產生。

## projects.yaml

Devbox 的已註冊專案清單。

## projects

每個已註冊的專案的專案設定檔和 Docker Compose 設定檔。

## build

Devbox 的共用 Docker Image 的建置檔案，包含 Dockerfile、entrypoint.sh、supervisord.conf 等。

## agents

Agent 相關的 Volume，目前只包含 Claude Code 的設定檔並使用 Bind Mount 綁定，其他都會使用 Volume 的綁定方式。

## locks

Devbox 的 lock 機制，避免同時操作資源導致 race condition。
