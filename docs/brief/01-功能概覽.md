# Devbox 功能概覽

這個是一個我的本地 Agent 開發環境，底層使用 Docker，可以快速啟動包含我常用程式環境的容器。

但唯獨最關鍵的功能差異是，Devbox 的設定檔一定是在使用者的 home 之下，會在每個目錄中初次設定好想要使用的專案的程式版本，比如 `devbox init` 設定了 Node.js v24 或 PHP 8.3，然後 `devbox build` 編譯 Docker Image，這樣就可以透過 `devbox up` 快速啟動，紀錄目錄設定檔的結構靈感來自像 Claude Code 或 Codex 本地保存 sessions 的方式。

因為我常常多個專案都會有類似的設定，但又不想要在團隊專案中加入 Dockerfile 之類的設定，我想要本地設定方式是，要既可以快速啟動，又想要保有我自己的 Agent 設定和客製的開發環境工具。

因此我對於實作的想像是，應該像是一個 Docker Compose 設定檔的產生器，會參考我在 prototype/ 下面實作調整出來的內容來產生；和 Docker 容器的啟動器，可能會包裹了 `docker up/down` 等指令的內容。
