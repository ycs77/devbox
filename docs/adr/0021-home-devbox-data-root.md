# Store host-side Devbox data under ~/.devbox

Devbox stores all of its host-side user-scope files under `~/.devbox` on Linux, WSL2, and macOS rather than using XDG or macOS-specific application directories. Local configurations, the Platform lock, generated Compose definitions, logs, and rebuildable cache use distinct subdirectories beneath this one predictable root; Docker-managed volumes remain in Docker storage. Project data mirrors the absolute Project root beneath `~/.devbox/projects/`: path separators form nested directories, while each path segment is reversibly escaped when needed for safe storage rather than replaced by an opaque hash. Each mirrored Project directory stores its supported human-editable Local configuration as `config.yaml`; the presence of that file registers the Project even when its contents are invalid, and Devbox discovers and reports such Projects by scanning these files instead of maintaining a separate central registry or index.
