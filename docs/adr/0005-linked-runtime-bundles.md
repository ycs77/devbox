# Assemble Workspace images from linked bundle layers

The initial Runtime catalog supports PHP and Node only, and a Toolchain may select PHP, Node, both, or neither. Devbox packages each selected Base-profile-compatible Runtime under an isolated path, then uses BuildKit `COPY --link` to assemble the selected bundles into one immutable Workspace image. This lets PHP and Node invoke each other directly in one Sandbox while identical bundle layers remain reusable across Toolchain combinations and Projects; the first release does not depend on experimental image mounts, install Runtimes during container startup, or couple Workspace image assembly to the selected AI Agent.

Each successfully assembled and verified Workspace image receives the stable local Docker tag `devbox-workspace:<fingerprint>`. The fingerprint's semantic inputs are the complete exact Base entry from the applicable Platform lock, the complete exact entry for each Runtime selected by the Toolchain and no unselected Runtime entry, and a versioned Devbox Workspace assembly recipe. The Project identity or path, ports, selected AI Agent, Local configuration fields that do not affect image assembly, generated Compose content, Sandbox container state and writable layer, Agent executable, and other mutable Sandbox state are excluded. Any change to an included Base, selected Runtime, or assembly-recipe input therefore produces another tag without changing running Sandboxes, while Projects with identical included inputs resolve to the same tag and image.

Fingerprint schema version 1 uses one constrained canonical JSON encoding rather than hashing ordinary YAML or serializer-dependent JSON and does not require the full RFC 8785 algorithm. Its fixed payload schema contains the fingerprint schema version, the Workspace assembly recipe version, the complete Base entry, and the selected Runtime entries. The encoder emits schema-defined object fields in fixed order, orders Runtime entries by family and then release line, emits no insignificant whitespace, uses one defined standard JSON string escaping, and permits only integers, strings, and objects; an empty Runtime selection is an empty object rather than an omitted or null field. Devbox hashes the resulting UTF-8 bytes with SHA-256 without truncation and formats the stable tag as `devbox-workspace:v1-<64 lowercase hexadecimal characters>`. Changing either the fingerprint schema version or the assembly recipe version invalidates prior identities through the fingerprint itself and requires no persistent generation metadata.
