# Assemble Workspace images from linked bundle layers

The initial Runtime catalog supports PHP and Node only, and a Toolchain may select PHP, Node, both, or neither. Devbox packages each selected Base-profile-compatible Runtime and AI Agent under an isolated path, then uses BuildKit `COPY --link` to assemble the selected bundles into one immutable Workspace image. The selected Agent is installed in a dedicated source stage of the same generated Workspace Dockerfile rather than directly in its final stage; this logical bundle boundary does not require a separate Dockerfile or published Agent image. This lets PHP, Node, and the Agent invoke each other directly in one Sandbox while identical bundle layers remain reusable across Toolchain combinations and projects; first releases do not depend on experimental image mounts or install Runtimes during container startup.
