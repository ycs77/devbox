# Install the latest AI Agent release from upstream

The initial AI Agent catalog supports Claude Code and Codex, and Codex inclusion is not gated on a separate packaging or authentication prototype. Devbox does not select or pin exact AI Agent versions. Each AI Agent has one current user-scope bundle shared by every project that selects it; when no bundle exists, the first operation that needs the Agent builds it automatically, while an existing bundle is replaced only through an explicit Agent update operation rather than `up` or ordinary `devbox update`. The update operation prepares and verifies a new bundle plus every existing Workspace image that uses the Agent, then atomically activates the entire generation only after every build succeeds; any failure leaves the old bundle and images active, and running Sandboxes remain unchanged until recreated. After activation Devbox retains no managed rollback generation, although Docker artifacts remain while referenced by an existing Sandbox. Each bundle build follows that Agent's official upstream installation path and installs whatever release it resolves as latest—for Claude Code, `curl -fsSL https://claude.ai/install.sh | bash`—deliberately favoring current Agent capabilities, predictable updates, cross-project reuse, and vendor-supported installation over exact build reproducibility.
