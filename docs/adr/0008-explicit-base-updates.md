# Require explicit Base updates

Global `devbox update` updates locked Runtime and Service artifacts but never changes the Base point release, revision, image digest, or profile. Base changes require the explicit `devbox update --base` form, which expands the same update to every locked Platform artifact and always targets the last, newest Base profile in Devbox's ordered Built-in list of supported profiles; when the active lock already uses that profile, it resolves the newest exact revision and digest within it. The Base list is Devbox package data rather than Project configuration, and users cannot select or pin a different profile. `--base` itself is complete consent to the cross-profile migration: the command displays the resolved plan but does not prompt again and behaves the same in interactive and non-interactive environments. It prepares and verifies the complete candidate Platform lock generation and every affected existing Workspace image before atomically activating the generation.
